# SQUEEZE - компрессор для FL Studio

Простой компрессор: одна главная ручка и три режима характера звука.

## Ручки

| Ручка | Что делает |
|---|---|
| **SQUEEZE** | Главная ручка. Крутишь вправо, звук прижимается сильнее (сама двигает threshold и ratio). |
| **PUNCH / GLUE** | Влево: транзиенты проходят, звук бьёт. Вправо: медленнее отпускает, всё склеивается. |
| **MIX** | Параллельная компрессия: сколько чистого сигнала подмешать. |
| **OUTPUT** | Громкость на выходе (±12 dB). |
| **AUTO GAIN** | Держит громкость до и после одинаковой, чтобы ты слышал качество, а не просто "стало громче". |

## Режимы

- **CLEAN** - прозрачный, для шины и мастера.
- **FAT** - агрессивный, быстрый, с сатурацией. Для рэп-вокала, 808 и барабанов.
- **SMOOTH** - мягкий, оптический. Ровняет вокал без следов.

Внутри всё работает само: фильтр сайдчейна (бочка и 808 не пампят весь микс), мягкое колено, авто-release, сатурация с овер­сэмплингом.

## Пресеты

Default, Vocal - Upfront, Vocal - Smooth, Vocal - Clean Level, 808 - Thick, Drums - Smash, Bus - Glue, Master - Gentle, Parallel - Fat. Выбираются в окне плагина или в меню пресетов FL.

## Установка (Windows)

1. Открой раздел **Releases** справа на странице репозитория и скачай `Squeeze-Windows-VST3.zip`
   (или **Actions** → последний запуск → артефакт `Squeeze-Windows`).
2. Распакуй. Внутри папка `Squeeze.vst3`.
3. Скопируй папку `Squeeze.vst3` в `C:\Program Files\Common Files\VST3`.
4. В FL Studio: **Options → Manage plugins → Find installed plugins** (Rescan).
5. Squeeze появится в списке эффектов (производитель: iboughtsomenew).

## Сборка

Собирается автоматически на GitHub Actions при каждом пуше в `main` (JUCE 8, CMake).
Вручную: `cmake -S . -B build && cmake --build build --config Release`.
